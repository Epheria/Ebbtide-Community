# 음성

> **UI·대본 번역 안내:** `ui`와 `voice-text`는 작업 범위 배정, 별도 검수자의 승인, 봇 제출 절차를 따릅니다. 먼저 [한국어 작업 안내](CONTRIBUTION_WORKFLOW.md)를 읽어 주세요. 아래의 Git 직접 편집·수동 PR 제출 절차는 이 두 종류의 번역에는 적용되지 않습니다. 파일 형식 설명은 계속 참고할 수 있으며, 녹음·오디션은 별도로 진행합니다.

*이 페이지는 AI의 도움을 받아 번역했습니다. 한국어가 모국어라면 풀 리퀘스트로 번역을 다듬어 주세요. 기준이 되는 문서는 [영어판](../../voice/README.md)입니다.*

지금 Ebbtide의 음성 대사는 모두 AI 음성이며, 전부 실제 성우의 목소리로 바꿀 예정입니다. 조종사, 헬기 승무원, 함정 장교, 차량 승무원, 보병 분대가 모두 여기에 해당합니다.

## 진행 방식

아래 경로는 모두 [`voice/`](../../voice/) 폴더를 기준으로 합니다.

1. **오디션.** Discord 제출 채널에 고정된 샘플 대사를 읽고, 짧게 녹음해서 올려 주세요.
2. **캐스팅.** 목소리가 배역에 맞으면 관리자가 연락드리고 비공개 티켓을 엽니다.
3. **대본.** 배역의 전체 대본을 [`scripts/<role>.csv`](../../voice/scripts/)에 추가합니다. 파일 이름, 상황, 톤, 대사가 들어 있습니다.
4. **녹음 전달.** 녹음 파일을 `takes/<role>/<your name>/`에 추가하는 풀 리퀘스트를 엽니다. 대사 하나에 파일 하나씩, 이름은 대본에 적힌 그대로 맞춰 주세요.
5. **검토.** 녹음을 듣고, 필요하면 다시 녹음을 부탁드린 뒤, 병합해서 다음 빌드에 넣습니다.

## 녹음 사양

잡음 없이, 아무 효과도 넣지 않은 원음으로 녹음해 주세요. 무전 효과는 게임에서 직접 넣습니다.

- FLAC을 권장합니다(용량이 더 작습니다). WAV도 됩니다. 모노, 48 kHz, 24-bit(44.1 kHz / 16-bit도 괜찮습니다).
- 리버브, 이펙트, 음악, 무전 필터는 넣지 마세요.
- 울림이나 배경 소음이 없는 조용한 방에서 녹음해 주세요.
- 가장 큰 피크는 -3 dB 안팎으로 맞추고, 클리핑은 절대 나지 않게 해 주세요.
- 파일 하나에 대사 하나만 담고, 앞뒤로 0.5초 정도 무음을 두세요.
