# 기여하기

*이 페이지는 AI의 도움을 받아 번역했습니다. 한국어가 모국어라면 풀 리퀘스트로 번역을 다듬어 주세요. 기준이 되는 문서는 [영어판](../../CONTRIBUTING.md)입니다.*

도와주셔서 감사합니다. 이 페이지는 실제 진행 절차를 다룹니다. 법적인 내용은 [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md)에 있습니다(영어로만 제공되며, 영어 원문이 공식 문서입니다).

## 시작하기 전에

1. 하려는 작업에 맞는 이슈를 먼저 열어 주세요([번역가](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml), [성우](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml)). 두 사람이 같은 작업을 겹쳐서 하는 일을 막기 위해서입니다.
2. 관리자의 답변을 기다려 주세요. 새 언어라면 관리자가 언어 폴더를 만들어 드립니다.

## 수정하는 방법

Git을 잘 몰라도 괜찮습니다. 아래 둘 중 편한 방법을 쓰면 됩니다.

- **브라우저에서:** GitHub에서 파일을 열고 연필 아이콘을 눌러 수정한 뒤, "Create a new branch and start a pull request"를 고릅니다.
- **내 컴퓨터에서:** 저장소를 포크해서 클론하고, 수정한 내용을 내 포크에 push한 뒤 풀 리퀘스트를 엽니다.

풀 리퀘스트 하나에는 언어 하나, 또는 성우 배역 하나만 담아 주세요. 그래야 리뷰하기 쉽습니다.

## 풀 리퀘스트 체크리스트

- [ ] 제가 직접 만든 작업물이며, AI로 만든 부분은 전혀 없습니다.
- [ ] [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md)에 동의합니다(영어로만 제공되며, 영어 원문이 공식 문서입니다).
- [ ] 번역: `translation` 열과 `status` 열만 수정했습니다.
- [ ] 음성: 파일 이름이 배역 대본과 정확히 같습니다.

## 리뷰

- 번역은 가능하면 그 언어가 모국어인 사람이 리뷰합니다. 보통 그 언어를 처음 맡은 숙련 번역가가 리뷰어가 됩니다.
- 리뷰어가 수정을 요청할 수 있습니다. 논의는 누구나 따라올 수 있도록 풀 리퀘스트 안에서만 합니다.
- 병합된 작업물은 바로 들어가지 않고, 다음 빌드 때 게임에 반영됩니다.

## 크레딧

첫 풀 리퀘스트에서 크레딧에 어떻게 표시되면 좋을지 알려 주세요(이름이나 닉네임, 원하면 링크도). 나중에 [CREDITS.md](../../CREDITS.md)를 고치는 풀 리퀘스트를 따로 보내서 바꿀 수 있습니다.
