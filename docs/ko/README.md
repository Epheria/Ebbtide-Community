# Ebbtide 커뮤니티

*이 페이지는 AI의 도움을 받아 번역했습니다. 한국어가 모국어라면 풀 리퀘스트로 번역을 다듬어 주세요. 기준이 되는 문서는 [영어판](../../README.md)입니다.*

[English](../../README.md) · [Español](../es/README.md) · [Русский](../ru/README.md) · **한국어** · [日本語](../ja/README.md) · [Polski](../pl/README.md) · [Türkçe](../tr/README.md) · [Français](../fr/README.md)

이곳은 커뮤니티가 함께 Ebbtide를 만들어 가는 곳입니다. 번역, 성우 연기 등 게임에 들어갈 여러 기여를 이곳에서 받습니다.

Ebbtide는 실시간 지휘를 더한 탑다운 좀비 생존 게임으로, 개발자 한 명이 만들고 있습니다. 게임의 많은 부분이 처음에는 AI로 만든 음성, 음악, 번역으로 채워졌습니다. 이 저장소의 목표는 이것들을 커뮤니티의 실제 사람들이 만든 작업물로 하나씩 바꿔 나가는 것입니다.

## 참여하는 방법

| 분야 | 시작하는 법 | 작업물이 들어가는 곳 |
| --- | --- | --- |
| 번역 | [번역가 이슈](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml)를 엽니다. 안내: [TRANSLATING.md](TRANSLATING.md) | [`localization/`](../../localization/) |
| 성우 연기 | Discord 제출 채널에서 오디션을 보거나 [성우 이슈](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml)를 엽니다. 안내: [VOICE.md](VOICE.md) | [`voice/`](../../voice/) |
| 음악, 사운드, 아트 | 먼저 Discord 제출 채널에 작업물을 올려 주세요 | 작업물이 채택되면 폴더를 새로 만듭니다 |
| 플레이테스트 피드백 | 플레이테스트가 열리면 참여해서 Discord에 알려 주세요 | 이 저장소에서는 받지 않습니다 |

## 기여한 작업이 게임에 들어가는 과정

1. 이슈로 신청하거나, Discord 제출 채널에서 선정됩니다.
2. [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md)를 읽어 주세요(영어로만 제공되며, 영어 원문이 공식 문서입니다). 작업물의 소유권은 계속 본인에게 있고, Ebbtide에서 쓸 수 있도록 허락만 하는 방식입니다.
3. 이 저장소를 포크해 작업물을 추가하고, 풀 리퀘스트를 엽니다.
4. 번역은 먼저 자동 검사를 거치고, 그다음 리뷰어가 풀 리퀘스트를 확인합니다.
5. 승인된 작업물은 이 저장소에 병합되고, 개발자가 다음 빌드에 반영합니다.

모든 기여자는 본인이 정한 이름으로 게임 크레딧에 올라갑니다.

## 기본 규칙

- 본인이 직접 만든 작업물만 제출해 주세요.
- AI로 만든 번역, 음성, 음악, 아트는 받지 않습니다. 사람이 직접 만든 작업물을 담는 것이 이 프로젝트의 핵심입니다.
- 리뷰는 친절하게 해 주세요. 이곳에 있는 사람 대부분은 자원봉사자입니다.

자세한 내용은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

## 현재 상황

- 번역: 참여할 수 있습니다. 영어 원문은 아직 개발 중인 게임의 한 시점을 옮겨 둔 것이라 텍스트가 바뀔 수 있습니다. 바뀐 줄은 자동으로 표시됩니다.
- 성우 연기: 오디션부터 진행합니다. 21개 배역의 대본은 모두 [`voice/scripts/`](../../voice/scripts/)에 있습니다.
