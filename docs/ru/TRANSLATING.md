# Локализация

*Эта страница переведена с помощью ИИ. Если русский для вас родной, помогите улучшить перевод через pull request. Эталоном считается [английская версия](../../localization/README.md).*

Текст интерфейса Ebbtide, готовый к переводу. Игра пишется на корейском, а английский служит исходником для всех остальных языков.

## Папки

Все пути ниже указаны относительно папки [`localization/`](../../localization/).

| Путь | Что там лежит |
| --- | --- |
| `source/strings/<Table>.csv` | Актуальный текст игры: `key`, `en`, `ko`. Не редактируйте: файл заново создаётся из игры. |
| `source/SNAPSHOT` | Дата и размер текущего снимка исходника |
| `translations/<lang>/<Table>.csv` | По одной папке на язык: `key`, `en`, `translation`, `status` |
| `glossary.csv` | Имена и военные термины и правила их перевода |

Папки языков называются кодами, например `de`, `fr`, `pt-BR`, `ro`, `zh-Hans`. Код русского — `ru`.

## Как переводить

1. Создайте [заявку переводчика (issue)](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml) для своего языка. Мейнтейнер создаст папку языка.
2. Редактируйте файлы в `translations/<lang>/`. Заполняйте только столбец `translation`.
3. Сохраняйте все плейсхолдеры точно как в английском тексте: `{0}`, `{1}`, теги форматирования вроде `<b>` и переносы строк `\n`. Внутри предложения их можно переставлять.
4. Имена и термины сверяйте с `glossary.csv`.
5. Откройте pull request. Автоматическая проверка сообщит о пропущенных плейсхолдерах или сломанных строках.

Если не уверены, оставьте `translation` в строке пустым. Пустая строка в игре покажется на английском.

### Редактирование CSV-файлов

- Для небольших правок подойдёт веб-редактор GitHub.
- Для больших объёмов используйте LibreOffice Calc или Google Таблицы. Импортируйте файл в UTF-8 с запятой как разделителем, а затем экспортируйте обратно в CSV в UTF-8 с теми же четырьмя столбцами.
- Не используйте Microsoft Excel, если только не сохраняете в формате "CSV UTF-8". Другие форматы ломают неанглийские символы, в том числе кириллицу.

## Столбец `status`

| Значение | Что значит | Что делать |
| --- | --- | --- |
| (пусто) | Всё в порядке или ещё не переведено | Если перевода нет — переведите |
| `outdated` | Английский текст изменился после перевода | Обновите перевод, затем очистите статус |
| `review` | Ревьюер хочет посмотреть ещё раз | Обсудите в pull request |

## Когда текст игры меняется

Игра ещё в разработке, поэтому английский текст часто добавляют, меняют и удаляют. Когда исходник обновляется, мейнтейнер запускает `python tools/l10n.py update`. Эта команда:

- добавляет новые строки с пустым переводом,
- помечает строки с изменённым английским текстом как `outdated` и сохраняет ваш старый перевод,
- удаляет строки, которых больше нет в игре.

## Для мейнтейнеров

```bash
python tools/export_unity_strings.py --project <path to the Unity project>  # refresh the source (needs PyYAML)
python tools/l10n.py update                                                 # sync every language
python tools/l10n.py init <lang>                                            # open a new language
python tools/l10n.py check                                                  # the same check the pull requests run
python tools/l10n.py status                                                 # progress per language
```

Сюжетные сцены (диалоги в катсценах) пока не включены. Их добавят, когда сценарий будет окончательным.
