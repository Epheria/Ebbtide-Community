# Как внести вклад

*Эта страница переведена с помощью ИИ. Если русский для вас родной, помогите улучшить перевод через pull request. Эталоном считается [английская версия](../../CONTRIBUTING.md).*

Спасибо за помощь! Здесь описаны практические шаги. Юридическая сторона — в [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (документ на английском, официальным считается английский текст).

## Перед началом

1. Создайте заявку (issue) на то, что хотите сделать ([переводчик](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml), [актёр озвучки](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml)). Так два человека не будут делать одно и то же.
2. Дождитесь ответа мейнтейнера. Для нового языка мейнтейнер сам создаст папку.

## Как вносить изменения

Хорошо знать Git не обязательно. Есть два способа:

- **В браузере:** откройте файл на GitHub, нажмите на значок карандаша, внесите правки и выберите "Create a new branch and start a pull request" (создать новую ветку и открыть pull request).
- **На своём компьютере:** сделайте форк репозитория, клонируйте его, внесите правки, отправьте их (push) в свой форк и откройте pull request.

Один pull request — один язык или одна роль озвучки. Так его проще проверить.

## Чек-лист для pull request

- [ ] Это моя собственная работа, и в ней нет ничего, созданного ИИ.
- [ ] Я согласен(-на) с [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (документ на английском, официальным считается английский текст).
- [ ] Переводы: я менял(-а) только столбцы `translation` и `status`.
- [ ] Озвучка: имена файлов точно совпадают со сценарием роли.

## Ревью

- Переводы проверяет носитель языка, если такой есть. Первый опытный переводчик языка обычно становится его ревьюером.
- Ревьюер может попросить что-то исправить. Обсуждение идёт прямо в pull request, чтобы все могли его видеть.
- Принятая работа попадает в игру со следующей сборкой, а не сразу.

## Титры

В первом pull request напишите, как указать вас в титрах (имя или ник и, по желанию, ссылка). Позже это можно изменить другим pull request в [CREDITS.md](../../CREDITS.md).
