Здесь сообщество помогает создавать Ebbtide: переводы, озвучка и другой вклад, который попадает в игру.

Ebbtide — зомби-выживание с видом сверху и командованием в реальном времени. Игру делает один разработчик. Во многих частях игры сначала стояли голоса, музыка и переводы, созданные ИИ. Цель этого репозитория — шаг за шагом заменить их работой живых людей из сообщества.

## Как помочь

| Направление | С чего начать | Куда идёт работа |
| --- | --- | --- |
| Перевод | Создайте [заявку переводчика (issue)](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml) | [`localization/`](../../localization/) (руководство: [TRANSLATING.md](TRANSLATING.md)) |
| Озвучка | Пройдите прослушивание в Discord-канале submissions или создайте [заявку актёра озвучки (issue)](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml) | [`voice/`](../../voice/) (руководство: [VOICE.md](VOICE.md)) |
| Музыка, звук и арт | Сначала покажите свою работу в Discord-канале submissions | Папку добавят, когда работу выберут |
| Отзывы с плейтеста | Присоединяйтесь к плейтесту, когда он откроется, и пишите отзывы в Discord | Не в этом репозитории |

## Как ваша работа попадает в игру

1. Подайте заявку через issue или пройдите отбор в Discord-канале submissions.
2. Прочитайте [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (документ на английском, официальным считается английский текст). Права на работу остаются за вами, а вы разрешаете использовать её в Ebbtide.
3. Сделайте форк этого репозитория, добавьте свою работу и откройте pull request.
4. Переводы проходят автоматические проверки, затем ваш pull request смотрит ревьюер.
5. Одобренную работу вливают (merge) сюда, и разработчик добавляет её в следующую сборку.

Каждого участника укажут в титрах игры под тем именем, которое он выберет.

## Основные правила

- Присылайте только свою оригинальную работу.
- Никаких переводов, голосов, музыки и арта, созданных ИИ. Весь смысл — в работе живых людей.
- Будьте доброжелательны в ревью. Большинство здесь — волонтёры.

Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Статус

- Перевод: открыт. Английский исходник — это снимок игры, которая ещё в разработке, поэтому текст будет меняться. Изменённые строки помечаются автоматически.
- Озвучка: сначала прослушивания. Сценарии для всех 21 роли лежат в [`voice/scripts/`](../../voice/scripts/).
