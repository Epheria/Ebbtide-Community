C'est ici que la communauté aide à construire Ebbtide : traductions, doublage et autres contributions qui finissent dans le jeu.

Ebbtide est un jeu de survie zombie en vue de dessus, avec du commandement en temps réel, créé par un seul développeur. Beaucoup d'éléments du jeu ont démarré avec des voix, de la musique et des traductions générées par IA. Le but de ce dépôt est de les remplacer, petit à petit, par le travail de vraies personnes de la communauté.

## Comment une contribution arrive dans le jeu

1. Postulez avec une issue, ou faites-vous repérer dans le salon des soumissions du Discord.
2. Lisez [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (en anglais ; c'est le texte anglais qui fait foi). Vous restez propriétaire de votre travail ; vous autorisez son utilisation dans Ebbtide.
3. Forkez ce dépôt, ajoutez votre travail et ouvrez une pull request.
4. Des vérifications automatiques tournent sur les traductions, puis un relecteur examine votre pull request.
5. Le travail validé est fusionné ici, et le développeur l'intègre dans la prochaine build.

Chaque contributeur est crédité dans le jeu, sous le nom de son choix.

## Règles de base

- Ne proposez que votre propre travail original.
- Pas de traductions, de voix, de musique ni de graphismes générés par IA. Tout l'intérêt, c'est le travail de vraies personnes.
- Restez bienveillant dans les relectures. La plupart des gens ici sont bénévoles.

Tous les détails sont dans [CONTRIBUTING.md](CONTRIBUTING.md).

## État d'avancement

- Traduction : ouverte. Le texte source en anglais est un instantané d'un jeu encore en développement, donc le texte va changer. Les lignes modifiées sont signalées automatiquement.
- Doublage : on commence par les auditions. Les scripts des 21 rôles sont dans [`voice/scripts/`](../../voice/scripts/).
