Tutaj społeczność pomaga tworzyć Ebbtide: tłumaczenia, aktorstwo głosowe i inne prace, które trafiają do gry.

Ebbtide to gra survivalowa o zombie z widokiem z góry i dowodzeniem w czasie rzeczywistym, tworzona przez jednego dewelopera. Wiele elementów gry powstało na start z głosami, muzyką i tłumaczeniami wygenerowanymi przez AI. Celem tego repozytorium jest zastąpienie ich, kawałek po kawałku, pracą prawdziwych ludzi ze społeczności.

## Jak praca trafia do gry

1. Zgłoś się przez issue albo zostań wybrany na kanale zgłoszeń na Discordzie.
2. Przeczytaj [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (dokument jest tylko po angielsku; oficjalną wersją jest tekst angielski). Twoja praca nadal należy do ciebie, a ty pozwalasz użyć jej w Ebbtide.
3. Zrób forka tego repozytorium, dodaj swoją pracę i otwórz pull request.
4. Tłumaczenia przechodzą automatyczne sprawdzenie, a potem twój pull request ogląda recenzent.
5. Zaakceptowana praca jest scalana tutaj, a deweloper dodaje ją do następnego buildu.

Każda osoba, która pomoże, zostanie wymieniona w grze pod wybraną przez siebie nazwą.

## Podstawowe zasady

- Wysyłaj tylko własną, oryginalną pracę.
- Żadnych tłumaczeń, głosów, muzyki ani grafiki generowanych przez AI. Chodzi właśnie o pracę prawdziwych ludzi.
- Bądź życzliwy w recenzjach. Większość osób tutaj to wolontariusze.

Szczegóły znajdziesz w [CONTRIBUTING.md](CONTRIBUTING.md).

## Status

- Tłumaczenie: otwarte. Angielski tekst źródłowy to migawka gry, która wciąż powstaje, więc tekst będzie się zmieniał. Zmienione wiersze są oznaczane automatycznie.
- Aktorstwo głosowe: najpierw przesłuchania. Skrypty dla wszystkich 21 ról są w [`voice/scripts/`](../../voice/scripts/).
