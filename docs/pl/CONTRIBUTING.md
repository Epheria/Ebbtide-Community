# Współtworzenie

*Ta strona została przetłumaczona z pomocą AI. Jeśli polski to twój język ojczysty, pomóż ją poprawić przez pull request. Punktem odniesienia jest [wersja angielska](../../CONTRIBUTING.md).*

Dzięki, że pomagasz. Ta strona opisuje praktyczne kroki. Kwestie prawne są w [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (dokument jest tylko po angielsku; oficjalną wersją jest tekst angielski).

## Zanim zaczniesz

1. Otwórz issue z tym, co chcesz zrobić ([tłumacz](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml), [aktor głosowy](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml)), żeby dwie osoby nie robiły tego samego.
2. Poczekaj na odpowiedź opiekuna projektu (maintainera). Dla nowego języka opiekun sam utworzy dla ciebie folder.

## Wprowadzanie zmian

Nie musisz dobrze znać Gita. Masz dwie drogi:

- **W przeglądarce:** otwórz plik na GitHubie, kliknij ikonę ołówka, wprowadź zmiany i wybierz „Create a new branch and start a pull request”.
- **Na swoim komputerze:** zrób forka repozytorium, sklonuj go, wprowadź zmiany, wypchnij je (push) do swojego forka i otwórz pull request.

Jeden pull request to jeden język albo jedna rola głosowa. Wtedy łatwo go sprawdzić.

## Lista kontrolna pull requesta

- [ ] To moja własna praca i nic w niej nie zostało wygenerowane przez AI.
- [ ] Akceptuję [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (dokument jest tylko po angielsku; oficjalną wersją jest tekst angielski).
- [ ] Tłumaczenia: zmiany dotyczą tylko kolumn `translation` i `status`.
- [ ] Głos: nazwy plików dokładnie zgadzają się ze skryptem roli.

## Recenzja

- Tłumaczenia sprawdza native speaker danego języka, jeśli ktoś taki jest dostępny. Pierwszy doświadczony tłumacz danego języka zwykle zostaje jego recenzentem.
- Recenzent może poprosić o poprawki. Dyskusja zostaje w pull requeście, żeby wszyscy mogli ją śledzić.
- Scalona praca trafia do gry z następnym buildem, a nie od razu.

## Napisy końcowe

W swoim pierwszym pull requeście napisz, jak mamy cię wymienić w napisach (imię lub nick, do tego opcjonalnie link). Możesz to później zmienić kolejnym pull requestem do [CREDITS.md](../../CREDITS.md).
