# Cómo contribuir

_Esta página se tradujo con ayuda de IA. Si el español es tu lengua materna, ayúdanos a mejorarla con un pull request. La [versión en inglés](../../CONTRIBUTING.md) es la referencia._

Gracias por ayudar. Esta página explica los pasos prácticos; la parte legal está en [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (está en inglés; el texto en inglés es la versión oficial).

## Antes de empezar

1. Abre un issue sobre lo que quieres hacer ([traductor](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml), [actor de voz](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml)), para que dos personas no trabajen en lo mismo.
2. Espera a que responda un mantenedor. Si es un idioma nuevo, el mantenedor crea la carpeta por ti.

## Hacer cambios

No hace falta saber mucho de Git. Tienes dos opciones:

- **En el navegador:** abre un archivo en GitHub, haz clic en el icono del lápiz, edítalo y elige "Create a new branch and start a pull request" (crear una rama nueva y abrir un pull request).
- **En tu PC:** haz un fork del repositorio, clónalo, edita, sube los cambios (push) a tu fork y abre un pull request.

Limita cada pull request a un solo idioma o a un solo papel de voz, para que sea fácil de revisar.

## Lista de comprobación del pull request

- [ ] El trabajo es mío y nada de él está generado por IA.
- [ ] Acepto [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) (está en inglés; el texto en inglés es la versión oficial).
- [ ] Traducciones: solo cambié las columnas `translation` y `status`.
- [ ] Voz: los nombres de archivo coinciden exactamente con el guion del papel.

## Revisión

- Las traducciones las revisa un hablante nativo de ese idioma cuando hay alguno disponible. Normalmente, el primer traductor con experiencia en un idioma pasa a ser su revisor.
- Un revisor puede pedir cambios. Las conversaciones se quedan en el pull request para que todos puedan seguirlas.
- El trabajo fusionado entra en el juego con la siguiente build, no al instante.

## Créditos

Dinos en tu primer pull request cómo quieres aparecer en los créditos (nombre o alias y, si quieres, un enlace). Puedes cambiarlo más adelante con otro pull request a [CREDITS.md](../../CREDITS.md).
