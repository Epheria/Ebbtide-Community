# 貢献ガイド

*このページは AI の支援を受けて翻訳しました。日本語が母語の方は、プルリクエストで改善にご協力いただけるとうれしいです。基準となるのは[英語版](../../CONTRIBUTING.md)です。*

ご協力ありがとうございます。このページでは実際の手順を説明します。法的な内容は [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) にあります（英語のみです。正式な版は英語の原文です）。

## 始める前に

1. やりたい作業について Issue を作成してください（[翻訳者](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml)、[声優](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml)）。2 人が同じ作業をしてしまうのを防ぐためです。
2. メンテナーの返信を待ってください。新しい言語の場合は、メンテナーがその言語のフォルダーを作成します。

## 変更の仕方

Git に詳しくなくても大丈夫です。次のどちらかの方法で進められます。

- **ブラウザーで**：GitHub でファイルを開き、鉛筆アイコンをクリックして編集します。最後に「Create a new branch and start a pull request」を選びます。
- **自分のパソコンで**：リポジトリをフォークしてクローンし、編集します。自分のフォークにプッシュしてから、プルリクエストを作成します。

レビューしやすいように、1 つのプルリクエストには 1 つの言語、または 1 つのボイスの役だけを含めてください。

## プルリクエストのチェックリスト

- [ ] この作品は自分で作ったもので、AI で生成した部分は一切ありません。
- [ ] [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) に同意します（英語のみです。正式な版は英語の原文です）。
- [ ] 翻訳：`translation` 列と `status` 列だけを変更しました。
- [ ] ボイス：ファイル名が役の台本と完全に一致しています。

## レビュー

- 翻訳は、可能であればその言語のネイティブスピーカーがレビューします。その言語で最初に参加した経験のある翻訳者が、そのままレビュアーになることがよくあります。
- レビュアーから修正をお願いすることがあります。誰でも流れを追えるように、話し合いはプルリクエストの中で行います。
- マージされた作品がゲームに入るのは次のビルドからです。すぐには反映されません。

## クレジット

最初のプルリクエストで、クレジットにどう載せてほしいかを教えてください（名前またはハンドルネーム。リンクも任意で付けられます）。あとから [CREDITS.md](../../CREDITS.md) への別のプルリクエストで変更することもできます。
