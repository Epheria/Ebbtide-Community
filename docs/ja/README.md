# Ebbtide Community

*このページは AI の支援を受けて翻訳しました。日本語が母語の方は、プルリクエストで改善にご協力いただけるとうれしいです。基準となるのは[英語版](../../README.md)です。*

[English](../../README.md) · [Español](../es/README.md) · [Русский](../ru/README.md) · [한국어](../ko/README.md) · **日本語** · [Polski](../pl/README.md) · [Türkçe](../tr/README.md) · [Français](../fr/README.md)

ここは、コミュニティのみなさんと一緒に Ebbtide を作っていく場所です。翻訳、ボイス、そのほかゲームに入るさまざまな貢献を受け付けています。

Ebbtide は、リアルタイムの部隊指揮を組み合わせた見下ろし型のゾンビサバイバルゲームで、開発者 1 人で制作しています。ゲームの多くの部分は、AI で生成したボイス・音楽・翻訳から始まりました。このリポジトリの目的は、それらをコミュニティの実際の人たちが作ったものへ、少しずつ置き換えていくことです。

## 協力の方法

| 分野 | 始め方 | 作業の置き場所 |
| --- | --- | --- |
| 翻訳 | [翻訳者用の Issue](https://github.com/Epheria/Ebbtide-Community/issues/new?template=translator.yml) を作成する | [`localization/`](../../localization/) (ガイド: [TRANSLATING.md](TRANSLATING.md)) |
| ボイス | Discord の作品投稿チャンネルでオーディションを受けるか、[声優用の Issue](https://github.com/Epheria/Ebbtide-Community/issues/new?template=voice_actor.yml) を作成する | [`voice/`](../../voice/) (ガイド: [VOICE.md](VOICE.md)) |
| 音楽・サウンド・アート | まず Discord の作品投稿チャンネルで作品を共有する | 作品が採用されたらフォルダーを追加します |
| プレイテストのフィードバック | プレイテストが始まったら参加し、Discord で報告する | このリポジトリでは扱いません |

## 貢献がゲームに入るまで

1. Issue で応募するか、Discord の作品投稿チャンネルから選ばれます。
2. [CONTRIBUTOR_TERMS.md](../../CONTRIBUTOR_TERMS.md) を読みます（英語のみです。正式な版は英語の原文です）。作品の権利はあなたが持ったままで、Ebbtide で使うことを許可する形になります。
3. このリポジトリをフォークし、作品を追加して、プルリクエストを作成します。
4. 翻訳には自動チェックが走り、そのあとレビュアーがプルリクエストを確認します。
5. 承認された作品はここにマージされ、開発者が次のビルドに取り込みます。

貢献してくれた方は全員、本人が選んだ名前でゲーム内のクレジットに載ります。

## 基本ルール

- 自分で作ったオリジナルの作品だけを提出してください。
- AI で生成した翻訳・ボイス・音楽・アートは受け付けません。実際の人の手による作品であることが、このプロジェクトのいちばん大事な点です。
- レビューでは思いやりのある言葉を使ってください。ここにいる人の多くはボランティアです。

詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) をご覧ください。
